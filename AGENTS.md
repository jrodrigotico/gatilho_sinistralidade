# Manutenção do README

Ao concluir uma tarefa que altere o código deste repositório, confira se a mudança afeta o que está descrito no `README.md`. Observe especialmente o fluxo do pipeline, os módulos, as dependências, as entradas e saídas e as regras por parceiro. Faça a mesma revisão se o usuário pedir para conferir a documentação após mudanças feitas fora do Codex. Nesse caso, considere o estado atual dos arquivos, incluindo mudanças ainda sem commit e commits recentes relevantes.

Se houver algo a atualizar, resuma em uma ou duas frases quais seções precisam mudar e pergunte ao usuário se quer atualizar o `README.md` agora ou deixar para depois. Encerre a tarefa de código normalmente, mantendo a edição do README pendente até receber uma resposta afirmativa. Um pedido explícito para atualizar o README já vale como autorização. Se a documentação continuar correta, dispense a pergunta.

Com a atualização autorizada, edite as seções afetadas em português e preserve o conteúdo que continua válido. Confira nomes de arquivos, referências e comportamento no código antes de descrever a mudança. Para verificar a documentação, use leitura estática do código. `run_gatilho.py` e funções de carga podem gravar ou sobrescrever tabelas Delta.
